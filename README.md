# Campus Navigation System
**Design & Analysis of Algorithms (DAA) Hackathon Project | APSH 2026**

## 1. Problem Statement
Navigating a large college campus efficiently requires finding the shortest path between various locations, such as academic blocks, libraries, cafeterias, and hostels. This project uses Breadth-First Search (BFS) and Dijkstra’s Algorithm to calculate optimal routes.

## 2. Algorithms Used
- **Dijkstra's Algorithm:** Calculates the shortest distance path in meters.
- **Breadth-First Search (BFS):** Finds the route with the fewest intersections/hops.
